# Калькулятор корректировки плотности

Локальное веб-приложение для расчета разбавления водой или утяжеления сухим реагентом по емкостям и по расчетной партии.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

После этого приложение будет доступно по адресу:

```text
http://127.0.0.1:4173
```

## Что считает

Плотность в `г/см3` численно равна `т/м3`, поэтому масса раствора:

```text
масса, т = объем, м3 * плотность, г/см3
```

Разбавление водой до меньшей плотности:

```text
Vводы = Vраствора * (rho_исх - rho_цель) / (rho_цель - rho_воды)
```

Утяжеление сухим реагентом до большей плотности:

```text
Vреагента = Vраствора * (rho_цель - rho_исх) / (rho_реагента - rho_цель)
масса_реагента, кг = Vреагента * rho_реагента * 1000
```

Температурная поправка применяется к введенной плотности:

```text
rho_расчет = rho_замер + коэффициент * (Tзамер - Tприведения)
```

По умолчанию коэффициент равен `0.0006 г/см3 на C`, его можно изменить в интерфейсе.

## Текущие возможности

- ввод емкостей: название, текущий объем, плотность, температура, максимальная вместимость;
- расчет воды или сухого реагента для каждой емкости;
- предупреждение о нехватке свободного объема;
- расчет времени подачи воды при заданной производительности в `л/с`;
- учет лимита реагента и фасовки мешка;
- сценарий расчетной партии с ручным или автоматическим отбором из емкостей;
- пошаговый план разбавления водой с контролем последнего дробного шага до целевой плотности;
- печатный отчет через кнопку `Печать`;
- выгрузка DOCX-рекомендаций по форме Вэл Инжиниринг через кнопку `Выгрузить DOCX`.
